### Part 7: Common Mistakes to Avoid

❌ **Don't**:
- Use broad match only (waste budget)
- Ignore negative keywords
- Set and forget (needs ongoing optimization)
- Compete on generic terms only
- Ignore mobile optimization
- Forget to track conversions

✅ **Do**:
- Use multiple match types
- Add negative keywords regularly
- Test different ad copies
- Focus on local keywords
- Optimize for mobile
- Track all conversions
- Monitor Quality Score
- Respond to all reviews
